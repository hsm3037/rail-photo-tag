현장 사진 태그 관리 - Android용 로컬 웹앱

구현 기능
- 갤러리에서 여러 사진 선택 후 등록
- 사진별 태그, 작업일, 메모 저장 및 수정
- 태그 생성/검색/필터
- 태그 템플릿 저장 및 불러오기
- 여러 사진 선택 후 태그 일괄 추가
- 날짜 범위 및 키워드 검색
- 엑셀에서 열 수 있는 CSV 내보내기
- 원본 사진 개별 다운로드
- 전체 사진/태그/템플릿 JSON 백업 및 복원
- IndexedDB 기반 로컬 저장. 사진 데이터를 앱 서버로 전송하지 않음

Android 설치/실행
이 파일 묶음은 APK가 아니라 설치 가능한 PWA 웹앱 소스입니다.
브라우저의 보안 정책상 안정적인 IndexedDB 저장과 홈 화면 설치를 위해 HTTPS 주소에서 최초 1회 열어야 합니다.
1) 이 폴더의 파일(index.html, manifest.webmanifest, sw.js)을 HTTPS 정적 호스팅(GitHub Pages 등)에 올립니다.
2) 갤럭시 Chrome에서 배포된 주소를 엽니다.
3) Chrome 메뉴 > 홈 화면에 추가 또는 앱 설치를 선택합니다.
4) 이후 앱을 실행하면 사진/태그는 해당 기기의 브라우저 저장공간(IndexedDB)에 저장됩니다.

중요
- 앱 데이터 삭제, Chrome 데이터 삭제, 기기 초기화 시 로컬 데이터가 삭제될 수 있습니다.
- 정기적으로 앱의 '내보내기·백업'에서 JSON 백업을 저장하세요.
- 이 버전은 APK가 아니며 Google Play 배포 앱도 아닙니다.
- 원본 사진 내보내기는 여러 장을 개별 다운로드합니다. Android 브라우저의 다운로드 확인 동작이 표시될 수 있습니다.
